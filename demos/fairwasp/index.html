How little must data change to be fair?

Created by Zikai Xiong · Based on Xiong, Dalmasso, Mishler, Potluru, Balch and Veloso [1]

Pre-processing is one way to make models fairer: it changes the training data, before any model is trained [1].
FairWASP edits no data point; it only changes how many times each application counts, and so indirectly affects any model trained on the data.

Two ways to make a bank’s loan data fairer. Which one changes the data less?

    The data and the rule

    500 applications per group, with income and credit score; income is a little higher in group A (mean \(+0.3\) standard deviations, \(-0.3\) in group B), credit score is not. Past decisions approved the half with the highest income \(+\) credit score \(+\) noise, with \(0.3\) subtracted in group B.

    Rule [1]: \(J\big(p_\theta(y\mid d),\,p_Y(y)\big)\le\varepsilon\) for every group \(d\) and decision \(y\), with \(J(p,q)=\max\{p/q,\,q/p\}-1\). Here \(p_Y(\text{approved})=50\%\), so \(\varepsilon=0.11\) allows approval rates from \(45.0\%\) to \(55.0\%\).

    FairWASP[1]

    drops some applications and copies similar ones
    Group A
    Group B

    Formulation \[\begin{aligned}&\min_{\theta}\ W(p_\theta,\,p_e)\\ &\text{s.t. } J\big(p_\theta(y\mid d),\,p_Y(y)\big)\le\varepsilon\quad\forall d,y\end{aligned}\]

    \(\theta_i\in\{0,1,2,\dots\}\), \(\sum_i\theta_i=n\): how many times application \(i\) counts; \(p_\theta\): the data with these weights, \(p_e\): the original data; \(W\): Wasserstein distance. Problem (4) of [1]; under a mild assumption, whole-number weights are optimal even among real-valued ones [1, Theorem 3]. Solved through the dual of its linear relaxation, which has only \(8\) unknowns.

    Reweighing[2]

    gives every application a new weight
    Group A
    Group B
    drag to turn

    Formulation \[\theta_i=w_{d_iy_i},\qquad w_{dy}=\frac{P(d)\,P(y)}{P(d,y)}\]

    \(d_i\), \(y_i\): group and decision of application \(i\). These weights make the approval rates exactly equal [2]; for a looser rule the page uses \(1+t\,(w_{dy}-1)\) with the smallest \(t\) that meets it.

      How much data had to move

      FairWASP

        Wasserstein distance

        \(W\): the least total weight \(\times\) distance needed to turn one dataset into the other. Two applications are at distance \(\sqrt{\Delta\text{income}^2+\Delta\text{credit}^2+\tfrac1{16}[\text{groups differ}]+[\text{decisions differ}]}\), with income and credit score in standard deviations. The group term's weight is a choice; with weight \(1\) instead of \(\tfrac1{16}\), the ratio at \(\varepsilon=0.11\) is 1.05.
