    What \(\mathrm{sym}(K)\) measures

    Definition

    For a convex body \(K\subset\mathbb R^n\) and \(x\in K\) [2],

    \[\begin{aligned}\mathrm{sym}(x,K)&=\max\{\alpha\ge 0:\,-\alpha(K-x)\subseteq K-x\},\\ \mathrm{sym}(K)&=\max_{x\in K}\,\mathrm{sym}(x,K),\end{aligned}\]

    and a maximizer \(x\) is a Minkowski center. \(\mathrm{sym}(K)\in[1/n,1]\), with \(\mathrm{sym}(K)=1/n\) if and only if \(K\) is a simplex, and \(\mathrm{sym}(K)=1\) if and only if \(K\) is centrally symmetric [1].

    Rounding factor as symmetry grows

    Guarantees

    (a), (b): \(\rho\le n\), and \(\rho\le\sqrt n\) if \(K\) is centrally symmetric [3, 4]. (c), (d): \(\rho\le\sqrt{n/\mathrm{sym}(K)}\) [1, Theorem 1.1], tight up to the factor \(\sqrt{2/3}\) [1, Theorem 5.1]. Here \(n=2\).
